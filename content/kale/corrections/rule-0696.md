(a) Roots ending in a nasal lengthen their penultimate vowel before a weak termination beginning with any consonant except a nasal or a semivowel, or before the affix @deva[क्विप्] @deva[शम्]—@deva[शान्त्], @deva[क्रम्]—@deva[क्रान्त्], &c

(b) Aniṭ roots ending in a nasal, the root @deva[वन्] 1. P. and the eight roots of the 8th class—@deva[तन्] and others (see p. 355) drop their nasal before a weak termination beginning with any consonant except a nasal or a semivowel:—

| Roots. | P. P Ptc. | | Roots | P. P. Ptc. |
|---|---|---|---|---|
| @deva[मन्] 'to think', &c. | @deva[मत] | | @deva[नम्] 'to bow' | @deva[नत] |
| @deva[हन्] 'to strike,' | @deva[हत] | | @deva[यम्] 'to restrain' | @deva[यत] |
| @deva[रम्] 'to sport' | @deva[रत] | | @deva[वन्] 1. P. 'to sound, to serve,' &c. | @deva[वत] |
| @deva[गम्] 'to go' | @deva[गत] | | @deva[घृण्] 'to shine' | @deva[घृत] |
| @deva[तन्] | @deva[तत] | | @deva[तृण्] 'to graze' | @deva[तृत] |
| @deva[क्षण्] | @deva[क्षत] | | @deva[वन्] 'to beg' | @deva[वत] |
| @deva[ऋण्] | @deva[ऋत] | | | |

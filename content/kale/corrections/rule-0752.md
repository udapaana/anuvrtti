title: "Application of Earlier Rules to Gerunds in @deva[य]"
pages: [442.png, 443.png]
verdict: approved-with-doubts
doubts:
  - "Glyph of कॄ / पॄ: long vocalic ṝ (printed with two marks); written कॄ, पॄ."
  - "ह्वे, दी, ली, दे roots read from print; दी (with उप—उपदाय) as printed."
---
The rules given at @ref[394], @ref[395], @ref[459], @ref[502] and @ref[587] apply to the roots also in the gerund in @deva[य]:—

| | |
|---|---|
| @deva[दिव्] with @deva[प्र]—@deva[प्रदीव्य] | @deva[वच्] with @deva[प्र]—@deva[प्रोच्य] |
| @deva[कॄ] with @deva[अव]—@deva[अवकीर्य] | @deva[वस्] with @deva[प्र]—@deva[प्रोष्य] |
| @deva[पॄ] with @deva[आ]—@deva[आपूर्य] | @deva[ग्रह्] with @deva[वि]—@deva[विगृह्य] |
| @deva[बन्ध्] with @deva[नि]—@deva[निबध्य] | @deva[ह्वे] with @deva[आ]—@deva[आहूय] |
| @deva[मि], @deva[मी], @deva[मा] and | @deva[दी] with @deva[उप]—@deva[उपदाय] |
| @deva[मे][^1] with @deva[अनु]—@deva[अनुमाय] | @deva[ली] with @deva[वि]—@deva[विलीय] or @deva[विलाय] |
| @deva[त्रै] with @deva[परि]—@deva[परित्राय] | &c. &c. &c. |
| @deva[दे] with @deva[आ]—@deva[आदाय] | |

[^1]: @deva[मे] changes its final to @deva[इ] optionally; so @deva[अनुमित्य] also.

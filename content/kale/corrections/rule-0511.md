## Optional Substitution of @deva[घस्] for @deva[अद्] in Perfect

@deva[घस्] is optionally substituted for @deva[अद्] in the Perfect.

| | Sing. | Dual | Plural |
|---|---|---|---|
| 1. | @deva[आद] | @deva[आदंव] | @deva[आदम] |
|  | @deva[जघास], @deva[जघस] | @deva[जक्षिव] | @deva[जक्षिम] |
| 2. | @deva[आदिथ][^1] | @deva[आदथुः] | @deva[आद] |
|  | @deva[जघासिथ] | @deva[जक्षथुः] | @deva[जक्ष] |
| 3. | @deva[आद] | @deva[आदतुः] | @deva[आदुः] |
|  | @deva[जघास] | @deva[जक्षतुः] | @deva[जक्षुः] |

[^1]: Vide @ref[515].

## Reduplication before @deva[आम्] in @deva[भी], @deva[ह्री], @deva[भृ], and @deva[हु]

When @deva[आम्] is added to the roots @deva[भी], @deva[ह्री], @deva[भृ] and @deva[हु] they are first reduplicated as in the third conjugation; e. g.—

**@deva[भी] 3. P. 'to fear.'**

|  |  |  |  |
|---|---|---|---|
| 1. | @deva[बिभाय, बिभय] | @deva[बिभ्यिव] | @deva[बिभ्यिम] |
|  | @deva[बिभयांचकार-चकर], &c. | @deva[बिभयांचकृव], &c. | @deva[बिभयांचकृम], &c. |
| 2. | @deva[बिभयिथ, बिभेथ] | @deva[बिभ्यथुः] | @deva[बिभ्य] |
|  | @deva[बिभयांचकर्थ], &c. | @deva[बिभयांचक्रथुः], &c. | @deva[बिभयांचक्र], &c. |
| 3. | @deva[बिभाय] | @deva[बिभ्यतुः] | @deva[बिभ्युः] |
|  | @deva[बिभयांचकार], &c. | @deva[बिभयांचक्रतुः] &c. | @deva[बिभयांचक्रुः] &c. |

**@deva[ह्री] 3 P. 'to be ashamed.'**

|  |  |  |  |
|---|---|---|---|
| 1. | @deva[जिह्राय, जिह्रय] | @deva[जिह्रियिव] | @deva[जिह्रियिम] |
|  | @deva[जिह्रयांचकार-चकर], &c. | @deva[जिह्रयांचकृव], | @deva[जिह्रयांचकृम], &c. |
| 2. | @deva[जिह्रयिथ-जिह्रेथ] | @deva[जिह्रियथुः] | @deva[जिह्रिय] |
|  | @deva[जिह्रयांचकर्थ] &c. | @deva[जिह्रयांचक्रथुः] &c. | @deva[जिह्रयांचक्र], &c. |
| 3. | @deva[जिह्राय] | @deva[जिह्रियतुः] | @deva[जिह्रियुः] |
|  | @deva[जिह्रयांचकार], &c. | @deva[जिह्रयांचक्रतुः], &c. | @deva[जिह्रयांचक्रुः], &c. |

**Additional forms:**

@deva[भृ]—@deva[बभार], @deva[बभर], @deva[बिभरांचकार]-@deva[बभूव]-@deva[रामास] 1 sing. @deva[हु]—@deva[जुहाव], @deva[जुहव]; @deva[जुहवांचकार]-@deva[बभूव]—@deva[वामास] 1 sing. &c.

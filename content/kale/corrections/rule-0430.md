@deva[दरिद्रा] P. 'to be poor'—drops its @deva[आ] before weak terminations beginning with a vowel and changes it to @deva[इ] before those with an initial consonant.

**Paradigms.**

**Present.**

| | Par. | | |
|---|---|---|---|
| | S. | D. | P. |
| 1. | @deva[दरिद्रामि] | @deva[दरिद्रिवः] | @deva[दरिद्रिमः] |
| 2. | @deva[दरिद्रासि] | @deva[दरिद्रिथः] | @deva[दरिद्रिथ] |
| 3. | @deva[दरिद्राति] | @deva[दरिद्रितः] | @deva[दरिद्रति] |

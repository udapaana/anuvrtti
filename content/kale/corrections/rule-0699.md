doubts:
  - "विरेभ्/विरेभित as printed (े clear on both pages); the participle is printed विरिब्ध."
  - "वाह्/वाढ: first letter could be ब (बाह्/बाढ)"
  - "फाणित: the print has the long ā, kept"

The following roots (some forming their P. P. P. irregularly) reject @deva[इ] in the limited sense attached to each:—

| | | | |
|---|---|---|---|
| @deva[क्षुभ्]—@deva[क्षुब्ध] | 'a churning handle.' | @deva[विरेभ्]—@deva[विरिब्ध] | 'a note.' |
| @deva[स्वन्]—@deva[स्वान्त] | 'the mind.' | @deva[फण्]—@deva[फाण्ट] | 'a decoction easily prepared.' (@deva[अनायाससाध्यः कषायविशेष] Sid. Kau.) |
| @deva[ध्वन्]—@deva[ध्वान्त] | 'darkness.' | | |
| @deva[लग्]—@deva[लग्न] | 'attached.' | | |
| @deva[म्लेच्छ्]—@deva[म्लिष्ट] | 'indistinct.' | @deva[वाह्]—@deva[वाढ] | 'much.' |

In their usual senses they have @deva[क्षुभित], @deva[ध्वनित], @deva[लगित], @deva[म्लेच्छित], @deva[विरेभित], @deva[फाणित] and @deva[वाहित].

The @deva[इ] of the root @deva[इ] P.[^1] 'to go' is changed to @deva[य्] before a weak vowel termination; @deva[एति] @deva[इतः] @deva[यन्ति] 3 pers. Pre.; @deva[आयम्] @deva[ऐव] @deva[ऐम] 1st Pers. Imperf., @deva[ऐः] 2 sing. Imperf.; @deva[अयानि], @deva[इहि], @deva[एतु] 1. 2. 3. sings. Imp.; @deva[यन्तु] 3 pl. Imp.

@deva[इ] with @deva[अधि] Â.[^2] 'to study.' &c. is regularly conjugated; as

**Present.**

| | Ātm. | | |
|---|---|---|---|
| | S. | D. | P. |
| 1. | @deva[अधीये] | @deva[अधीवहे] | @deva[अधीमहे] |
| 2. | @deva[अधीषे] | @deva[अधीयाथे] | @deva[अधीध्वे] |
| 3. | @deva[अधीते] | @deva[अधीयाते] | @deva[अधीयते] |

[^1]: @deva[ई] P. 'to go' is conjugated regularly like @deva[वी]—@deva[एति] @deva[ईतः] @deva[इयन्ति] 3rd Pers. Pre.; @deva[ईहि] 2 sing. Imp. @deva[इयन्तु] 3 plural Imp.
[^2]: @deva[इ] with @deva[अधि] P. 'to remember' should be conjugated like @deva[इ], @deva[अधियन्ति] 3rd pl. Pre. Some think that it is to be conjugated like @deva[इ] in the Non-conjugational tenses only. According to them the third pers. plu. will be @deva[अधीयन्ति]. The line of Bhaṭṭi '@deva[सतीतयो राघवयोरधीयन्]' III. 18 &c. is quoted in support of this opinion. @deva[केचित्तु आर्धधातुकाधिकारोक्तस्यैवातिदेशमाहुः । तन्मते यण्न ।] Sid. Kau.

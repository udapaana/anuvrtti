## అష్టషష్ఠితమః పాఠః = అఱువదియెనిమిదవ పాఠము.

కృత్యః, కుత్రత్యః = ఎక్కఁడివాఁడు &emsp;&emsp; భాతి = ప్రకాశించుచున్నాఁడు,

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ఎక్కఁడిది &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; తోచుచున్నాఁడు

ప్రాచ్యః = తూర్పువాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; వాతి = వీచుచున్నాఁడు

దాక్షిణాత్యః = దక్షిణపువాఁడు &emsp;&emsp;&emsp;&emsp;&emsp; మాతి = ఇముడు-కొలు

పాశ్చాత్యః = పడమటివాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; చున్నాఁడు

ఔత్తరాహః = ఉత్తరపువాఁడు &emsp;&emsp;&emsp;&emsp;&emsp; యాతి = వెళ్ళుచున్నాఁడు

భాగః = భాగము &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; యాపయతి = గడపు-పంపు

పూర్ణః = నిండినవాడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; చున్నాఁడు

సువర్ణం = బంగారము &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ప్రయాతి = ప్రయాణమగుచున్నాఁడు

విందతి = పొందుచున్నాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; గిళతి = మ్రింగుచున్నాఁడు

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; విభజ్య = భాగించి

తే బాలకాః కుత్రత్యాః వా ప్రష్ట్వాపి ఆగచ్చ. తే సర్వేపి దాక్షిణాత్యాః ఏవ; తేషాం వస్తాదిక మేవ కథయతి. తే ఔత్తరాహాః భవేయురితి. పాశ్చాత్యానాం అస్మాకంచ భేదః సమ్యక్ దృశ్యతే. తేషాం వర్ణః శ్వేతః అస్మాకంతు నీలవర్ణః. తస్మాదేవ తేషాం శ్వేతముఖా ఇతి నామధేయం అస్తి. త్వత్సమీపే స్థితం

సర్వమపి ధనం విభజ్య అర్థభాగం తవ అనుజాయ దేహి. తటాకః కదా పూర్ణః? సర్వమపి ధనం విభజ్య అర్థభాగం తవ అనుజాయ దేహి. తటాకః కదా పూర్ణః? సమ్యక్ అవర్తలు. ఏకస్యాం ప్రపూర్వేద్యుః [రాత్రిందివం = రేయింబగలు] సమ్యక్ అవర్తతు. రాత్ర్యాం ఏవ సంపూర్ణః ఆసీత్. ఇతఃపరం వత్సరచతుష్టయపర్యంతం జలస్య క్షాముః నాస్తి. [శాలిక్షేత్రాణి = వరి పొలములు] ఏతదవత్సరే సమ్యక్ ఫలిష్యంతీతి జ్ఞాముః నాస్తి. అరే తవ గుణాః మహ్యం న రోచంతే. తవ సమాచారః సుతరాం సమ్యక్ భాతి. అరే తవ గుణాః మహ్యం న రోచంతే. తవ సమాచారః సుతరాం సమ్యక్ నాస్తి. ఇతః ప్రభృతి [ప్రాతఃఉత్థాయ = ప్రాతరుత్థాయ] స్నానం శీతోదకే కురు. అనంతరం సంధ్యావందనాదికం యథావిధి కురు. తతః హ్యస్తనశోకచింతనాం కురు. అద్య పఠనీయం పాఠం సమ్యక్ విచారయ. ఏవంచే త్రవ వచనం అంగీకరిష్యామి; నోచేత్రవ గతి స్తవ; మామ గతి ర్మము. జ్ఔషధం కథమపి గిళ. ఆరోగ్యం శీఘ్రమేవ విందేః.

నిన్నఁ నేను [గృహాచారముచాలక = గృహాచారహీనాః] సంభావన కొనసము పెండ్లిచోటునకు వెళ్ళితిని. సంభావన లేదు. సరిగదా యజమానుఁడు కఱతీసికొని నన్నుఁ కొట్టవచ్చినాఁడు. నీ విప్పుఁడు డెక్కడికి ప్రయాణమగుచున్నా వయ్యా? ఎక్కఁడికని అడిగినావు ; శకునము బాగుగనేయున్నది. ఇంక నాపని బాగుగనే నెరవేరును. అటుల నెప్పుఁడును [అడుగరాదు = న ప్రష్టవ్యం] అందుచేతనే నేను నిన్నఁ దుఃఖమును అనుభవించితిని. నీ బట్టలు నా పెట్టెలో (పట్టువు = ఇముడవు) గనుక నీపెట్టెలోనే [పెట్టుకొనుము = నిక్షిప] మొరెటులైన ముహూర్తమును గడపి వెళ్ళుఁడు. నాభాగమును నాకు పంచిపెట్టుము. మా యూరు సముద్రపుకొఱ్ఱన నున్నది; గనుక అక్కఁడ నెండకాలపు భాదలేదు. మొకేమండి మొరెప్పుఱిదను డబ్బుతో నిండినవారు. నా దగ్గర నేమి యున్నది? ఒక దమ్మిడియును లేదు. నీవు చాల చతురుఁడవుగాని ఇఁక నూరకుఱేదుము. [నాకంటె = మదపేక్షయా] నీవే డబ్బుతో నిండినవాఁడవు. నీవెంత మాత్రము దరిద్రుఁడవు కావు. వట్టిమాటలతో నేమి ప్రయోజన మున్నది? తెచిపో...

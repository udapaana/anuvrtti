## చతుష్షష్ఠితమః పాఠః = అఱువదినాల్గవ పాఠము

కంకతికా = దువ్వెన &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; వ్రణః = కురుపు

శివకః = గూటము &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సాంద్రః = దట్టనిది

పుంఖః = పిడి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; దర్శందర్శం = చూచిచూచి

గోధనం = ఆలమంద &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; బంధంబంధం = కట్టికట్టి

అజకం = మేకలమంద &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; అకృత్వా = చేయకుండ

యూకా = పేను &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; శ్రుత్వా = విని

లిక్షా = ఈపి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; చిత్వా = ప్రోగుచేసి

సామా = గఱ్ఱి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; విశ్వాసయతి = నమ్మించుచున్నాఁడు

గ్రంథిః = ముడి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; దోలయతి = ఊగుచున్నాఁడు

అలర్కః = వెళ్ళికుక్కఁ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ప్రసాధయతి = చిక్కుతీయు

ద్రష్టవ్యః = చూడవలసిన &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

క్షాళయితవ్యః = కడుగఁబడవలసినది &emsp; శ్రృణోతి = వినుచున్నాఁడు

సులభః = దొరకునది &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; శ్రోష్యతి = వినఁగలఁడు

దుర్లభః = దొరకనిది &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; చినోతి = ప్రోగుచేయుచున్నాఁడు

శామ్యతి = తగ్గిపోవుచున్నది &emsp;&emsp;&emsp;&emsp;&emsp; చేష్యతి = ప్రోగుచేయఁగలఁడు

తాతాచార్యస్య పుత్రః గతదినే ఏకం శ్వనకం దండేన అతాడయత్. శ్వనకః అలర్కః. తస్మాత్కారణాత్ సః శ్వనకః తాతాచార్యస్య పుత్రం అప్పులాచార్యం పాదం అదశత్. అనంతరం కతిచిద్దినాని గతాని - తదానీంతా

సర్వాపి అశామ్యత్. ఇదానీం తత్పాదే ఏకః వ్రణః ఉదతిష్ఠత్కిల. తం బాలకం (వైద్యాలయం = ఆసుపత్రికి) అనయన్. వైద్యః వ్రణం అచ్చేదయత్. ఇతఃపరం కథంభవిష్యతివా కేన జ్ఞాయతే. హేఅంబ! అనుజస్య మస్తకే అతీవ యూకాలిక్షం అస్తి. తం ఆహహాయ కంకతికయా తత్సర్వం అపనయ. రే రామ! అవరణే ఏకం శివకం (నిఘాయ = ప్రొతి) తత్ర మహిషం బధాన. తత్రస్థితం గోధనం అజకం చ వనం చారయ. బలిద్ధాచార్యాయ సీతాపతిః ప్రథమతః కన్యాం దాస్యామోతి కథయిత్వా అంతః తం ఆవంచయత. కిమరే ఏవం విశ్వాస్య కంఠచ్చేదనం యుక్తం కిం? యుష్మద్దా మే గుడం దుర్లభం కిం? ఘరట్టుపుంఖః కుత్రాస్తి వా పశ్య. గృహే తందులపిష్టం నాస్తి. ఈషత్ భ్రామయిష్యామి. ప్రథమతః కన్యకాం ద్రష్ట్వా. అనంతరం వివాహాః ఆలోచయితవ్యః. అద్య ఆకాశే మేఘాః సాంద్రాః సంతి. బహుళఒ వర్థం పతిష్యతి కింవా. పతిష్యతిచే ద్వయం సర్వేపి కృతారాః ఏవఖలు.

మొతండ్రి యేమో చెప్పఱిచున్నాఁడు వినిరమ్ము. నీవు చెఱువుదగ్గరకు వెళ్ళుచున్నావు; గనుక స్నానము చేయకుండ రావద్దు. మల్లెచెట్టుక్రింద పూవులు పడినవిగాని ప్రోగుచేయుము. అరే నీశరీరమునందు అంతటను గఱ్ఱి అట్లున్నఁ దేమిరా? వైద్యుని యొద్ద నొషధము పుచ్చుకొనుము. మాదున్నఁ యెక్కఁడికో పాఱిపోయినది. చూచి చూచి వచ్చినాను. ఎక్కఁడను కనఁబడలేదండి. నన్నుఁ పురాణము చెప్పఱిమనెదవుగదా. ఎవరు వినఁగలరు? నేను ఒకఁడను వినఁగలను గదా! సరియే నీవు వినుము. నేను చెప్పెదను. నాకు బలము తగ్గిపోవుచున్నదిరా. ఇఁకమొంద చలినీటిలో స్నానమును చేయఁజాలనురా. పిల్లను ఊచుము; ఎందుకు నన్నుఁ జూచి నవ్వెదవు? నవ్వించుచున్నాఁవు గనుక నేను నవ్వుచున్నాను. నీ కాలిమొంద పుండెట్లున్నది? బొత్తుగా తగ్గిపోయినది. పిల్లకాయ లందఱును నా మాటలను వినుచున్నారు. అయ్యా! మాకు మిక్కిలి డబ్బున్నదిగదా. దరిద్రులవలె మీఁ అమ్మాయి పెండ్లిని గుళ్ళో చేసితిరేమి? ఈ కఱువు కాలములో నిశ్చే చేయవలె.

## త్రిసప్తతితమః పాఠః = డెబ్బదిమూఁడవ పాఠము

మధ్యమః = నడిమివాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ధ్వాయతి = ధ్వానించుచున్నాఁడు

నదీ = ఏఱు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; స్మరతి = తలచుచున్నాఁడు

అంతికా = పొయ్యి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; విస్మరతి = మఱుచుచున్నాఁడు

వేణుః = వెదురు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; క్రందతి = ఏడ్చుచున్నాఁడు

దళం = బ్రద్ధ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సాంత్వయతి = ఓదార్చుచున్నాఁడు

దాళి = పప్పు ఏ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; లాలయతి = బుజ్జగించు

మదీయః = నావాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

త్వదీయః = నీవాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; దహతి = కాల్చుచున్నాఁడు

తదీయః = వానివాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; వహతి = మోయుచున్నాఁడు

మత్స్యార్జికి = పొన్నుఁ గంటికూర &emsp;&emsp;&emsp; ప్రవహతి = పొంకుచున్నది

మునిః, బుషిః = ముని &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ప్రస్ఫోటతి = చెరుగుచున్నాఁడు

మహానసం = వంటయిల్లు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; జయతి = గెలుచున్నాఁడు

అగ్నిః = నిప్పు ఏ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ఉత్పతతి = ఎగురుచున్నాఁడు

శూర్పం = చేట &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ఉదయతే = ఉదయించు

పేటతి = అల్లుచున్నాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

పేషయతి = పిసుకుచున్నాఁడు &emsp;&emsp;&emsp;&emsp; అస్తమయతే = అస్తమించు

సేవతి = సేవించుచున్నాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

తాతాచార్యస్య జ్యేష్ఠపుత్రః బలిద్ధాచార్యస్య తృతీయ పుత్రికాం పరిణేతుం ప్రయత్న మకరోత్. కింతు బలిద్ధః స్వస్య కనిష్ఠపుత్రికాం దాతుం ఇచ్చత కుత ఇతిచేత్. తృతీయపుత్రికా అతీవ రమణీయా; తస్మాత్ తస్యాఽయథా కథంవా వివాహాః భవిష్యతి. పరంతు కనిష్ఠాయాఽ సౌందర్యం నాస్తి; తతః తస్యాఽ వరః న లభ్యతే. యథాకథంవా తాతం వంచయిత్వా కార్యం సాధయితుం(ప్రయతేఽ = ప్రయత్నించుచున్నాఁడు) పూర్వకాళే వేకుదళఽ పేటికాం పేటంతి స్మ. (మదీయః జనకః = నా తండ్రి) నద్యాం స్నాతుం అగచ్చత్. ఏతదంతరే అంతికాయాం అగ్నిం ప్రవేశయ. మత్స్యార్జికాకం

భేదయిత్వా తత్ర నిక్షిప. ముద్గదాళిం ఆనయ. సూపం కరిష్యామి. శూర్పే తందులాని నిక్షిప్య ఈషత్ ప్రస్ఫోటు. స్తనపః క్రందతి కింతు. అంబ! కించిత్ తం సాంతయ. (త్వాం వినా = నీవుతప్పు) బాలకం కా లాలయతి? దోలాయాం శయ్యా సమ్యక్ అస్తివా నవా పశ్య; అస్తిచేత్ తత్ర శాయయిత్వా దోలయ. నిద్రాస్యతి. గోధూమపిష్టం సమ్యక్ గవేషయఽ కిం? యుష్మద్దా మే నది సర్వదా ప్రవహతి కిం? అహాం ప్రయామి; కదాపి మాం మా విస్మర. సూర్య ఉదయతే. ఇతోపి(శయావృతఽ = ప్రక్కమొంద నుండి నోత్థాస్యసి కిలరే?&కస్థిష్యామి.

సూర్యుఁడస్తమించుచున్నాఁడు. నక్షత్రము లుదయించుచున్నవి. ఈనాఁడు చంద్రుఁడుదయించఁడు. ఇప్పుడు కృష్ణపక్షముగదా. మరల శుక్ల పక్షము వచ్చునెడల చంద్రుఁడు కనఁబడును. ఇప్పు దుత్తరాయణమా. దక్షిణాయనమా? రాముఁడు నన్నెప్పుఁడైనను తలంచుచున్నాఁడా? ఆ పిల్ల లందఱిను రస్తాయం దెగురుచున్నారు చూడుము. కుంతీదేవికి నడిమి కొడుకు అర్జునుఁడు. నా నొసట బొట్టున్నదా లేదా? లేనియెడల చెప్పఁఱిము; మరలం బెట్టుకొందును; మా నాన్నఁ కోపము చేయును. నీకాలిమొంద వ్రణము (మానినదా? = అశామ్యత్ కిం?) ఇంకను నన్నుఁ బాధించుచున్నది. అలాగా! అటువంటి కాలితో ఎందుకు నడచుచున్నావు? నేను తప్పు మాఇంటిలో నెవరున్నారు? మా నాన్నఁగారు మూసలివారుగదా! మా అన్నయ్యఁ కుంటివాఁడు; కాఁబట్టి నేనే బజారునకు పోవలయును. ఇటుల నుండియే నిన్నఁ యెందుకురా కఱ్ఱను కాలుచున్నావు? లేదు లేదు. ఆ ధాన్యమును చేటలో పోసి యెందలో నుంచుము. కొంచెము నిప్పును తెమ్ము; నేతిని కఱిగించెదను. రాముసికాలు విరిగినది. పొన్నుఁగంటి కూరలో కందిపప్పుఁగాని పెసరపప్పు ఏ గాని పడవేయుము.

## ఏకసప్తతితమః పాఠః = డెబ్బదియొకటవ పాఠము

క్రియమాణః = చేయఁబడుచున్న &emsp;&emsp;&emsp;&emsp; సంకుచతి = ముడుచుకొనుచున్నాఁడు,

సిక్తః = తడుపఁబడిన &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; లోహితాయతి = ఎఱ్ఱబాఱు

బద్ధః = కట్టఁబడిన &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

ముక్తః = విడువఁబడిన &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; వ్రషస్యతి = ఎదపుచున్నది

భృష్టః = వేగించఁబడిన &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; పరిష్మరోతి = పరిష్కరించు

కీటకః = పురుగు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

సద్భావః = ఉండుటు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; అపహారతి = అపహరించు

ఘాసః = గడ్డి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

ఘోషః = పల్లె &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; వ్యవహారతి = వ్యవహరించు

గ్రామః = ఊరు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

ఘూణః = గానుగ

సమాప్తః = ముగిసిన &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సంహారతి = చంపుచున్నాఁడు

తిలఘాతకః = తెలికలవాఁడు &emsp;&emsp;&emsp;&emsp;&emsp; అవహంతి = దంపుచున్నాఁడు

శ్రామ్యతి = అలయుచున్నాఁడు &emsp;&emsp;&emsp;&emsp; అవఘ్నంతి = దంపుచున్నాఁడు

మూహి = కొల్చుము, &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; దళతి = పగులుచున్నది

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [ఇముడుము &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; విదారయతి = చీల్చుచున్నాఁడు

యుష్మాభిః క్రియమాణం కార్యం సమాప్తంచేత్ భో శిష్యాః! శీఘ్రం పుష్పవనం గత్వా స్వామిపూజార్థం పుష్పాణి అనయత. హాంజే! దేవాలయే దీపఃఆస్తివా నవా పశ్య. తైలాభావాత్ నక్త మేవ దీపః ఆశామ్యత్. తర్హి తిలఘాతకగృహం గత్వా తైల మానయేతి రామంప్రతి వద. తద్దైవ వదిష్యామి. తిలఘాతకః ఇదానీమేవ తిలాన్ ఘూణాయాం పూరయిత్వా ఘూణాం భ్రమయితుం ఆరభత. ఈషత్కాలం స్థిత్వా ఆగచ్చేతి అవదత్. చణకాః భృష్టాః కింవా అంబాం ప్రచ్చ. అస్మద్వృత్తుః అవరణే శివకే కేన బద్ధః? యుష్మద్వృత్తున్ రాత్రా అహా మబధ్నాం. అద్యప్రాతః సుబ్రహ్మణ్యః పునరపి అమోచయత్.

పూర్వేద్యుః తటాకే మగ్నః గజః కుత్రా గచ్చత్? ఏకః అలర్కః అస్మద్దా మే పూర్వేద్యుః తటాకే మగ్నః గజః కుత్రా గచ్చత్? ఏకః అలర్కః అస్మద్దా మే సంచరతి; తం పాదే అతాడయన్; తస్య పాదః భగ్న అసీత్. సః ఇదానీం కుత్రాస్తి వా నజ్ఞాయతే. మమాంగవస్త్రం కేన సిక్తం? ఘోషాత్ గోపికా ఆగతా వా? నహి. రేరే తైలపిష్టే కీటాః ఇత స్తతశ్చలంతి. శోధయ. యుష్మాకం ధనసద్భావాత్ యథాపేక్షితం తథా భేలధ. అస్మాకం కి మస్తి? వయం సర్వదా నిర్గ్నాః అస్మద్గృహళా అవప్రసృత్ కింవా కంచన ఢంకం మార్గయ రే. మాషాన్ మానికయా మాహి.

మా పిల్లవాఁడు చదివి చదివి మిక్కిలి అలసినాఁడు. సూర్యుఁడు కొంచెము కొంచెము ఎఱ్ఱబాఱుచున్నాఁడు. నా చెంబు నెవఁడో అపహరించుచున్నాఁడు చూడుము. ఒక సింహము నిన్నటి యేనుఁగును గోళ్ళతో చీల్చుచున్నది. ఇఁక నీవు వంటు చాలించుము. (చాల ప్రొద్దయినది = మహాన్యాఽలో గతీ) కొంచెము నూనెనిటు తెమ్ము. శరీరమునందు పూసికొని స్నానము చేయుదును. పాముపఱుగిడుచున్నది. చంపుము. ఎవఁడు సంహరింపఁగలఁడు? (నేను చంపలేను = మారయితుం న శక్నోమి) మల్లెపూవులు ముడుచుకొనుచున్నవి. (కాకులు కూయుచున్నవి = కాకా రటంతి) మీఁ యింటిలో ధాన్యమును దంపుచున్నా రేమి? రేపు మా తాతగారి పెండ్లి. నీ కాలిమొంద కురుపు పగిలినదా? లేదు; ఇంకను చాల బాధపెట్టుచున్నది. మినపప్పు చ్చులను తినుము. రేపోయెల్లుండో పగులఁగలదు. తొలుకాని పోతేదు? ఇప్పుడేగా ఎనిమిదిగంటలు అయినది; గాఁడు పదిగంటల్లైన తర్వాత తొలుకాని పోతేదు? ఇప్పుడేగా ఎనిమిదిగంటలు అయినది; పదిగంటలైన తర్వాత గదా వాఁడు ప్రతిదినమును వచ్చును; (ఇంతలోనే వాఁడే వచ్చును. త్వరపడెదవేల = ఏతదంతరే ఏవ త్వరసి కిం?) కొంచెము కాలమును చూడుము

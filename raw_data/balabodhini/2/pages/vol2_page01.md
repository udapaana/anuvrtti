# బాలబోధినీ

ఏకోనచత్వారింశః పాఠః = ముప్పదితొమ్మిదవ పాఠము

సా = ఆమె &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; అభిముఖం = ఎదురుగా

ఏషా = ఈమె &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; పరితః = చుట్టుకొని

కా = ఎవతె? &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ఈషత్ = కొంచెము

సర్వా = ప్రతిది &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; పరశ్వః = ఎల్లుండి

అన్యా = మఱియొకతె &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ప్రహ్యః = మొన్న

లంబ్ = వ్రేలాడుట

వర్తమానకాలము &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; భూతకాలము

ప్ర. లంబతే - లంబంతే &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; అలంబత - అలంబంత

మ. లంబసే - లంబధ్వే &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; అలంబథాః - అలంబధ్వం

ఉ. లంబే - లంబామహే &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; అలంబే - అలంబామహి

&emsp;&emsp; సా అంగనా కస్య పుత్రికా వా, కిమర్థం గంగాసమీపే సంచరతి వా ఇతి ఏకః నృపః మాం ప్రహ్యః అపృచ్ఛత్. తదా అహాం ఈషత్ అలోచ్య 'హేనృప! అహమపి తద్వృత్తాంతం సర్వం విచార్య అనంతరం వదిష్యామి; తావత్పర్యంతం అత్ర ఏధి' ఇతి అవదం. తతః సః భూపాలః గంగాతీరే ఏకస్మిన్ లతాగృహే ఈషం త్వర్యంతం ఉషిత్వా, పునః అపి బహిః ఆగత్య మాం అహ్వాయత్. తదుపరి అహం రాజసమీపం గత్వా 'హేభూపాల! ఏషా మద్వచనస్య ప్రతుత్తరం నాయచ్ఛత్. కింతు అహం పునః పునః అపృచ్ఛం; తథాపి సా తూష్ణీం ఆసీత్, త్వమేవ గత్వా ప్రచ్ఛ-ఇతి తం నృపం అవదం పశ్చాత్ సః నృపః తథా ఏవ అకరోత్.

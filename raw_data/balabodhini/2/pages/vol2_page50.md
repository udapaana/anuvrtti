## పంచషష్ఠితమః పాఠః = అఱువదియైదవ పాఠము

పుంలింగము-ఉకారాంతము &emsp;&emsp;&emsp;&emsp;&emsp; నపుంసకలింగము-ఉకారాంతము

"గురు" శబ్దము = గురువు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; "మధు" శబ్దము = తేనె

&emsp;&emsp; ఏ. &emsp;&emsp; బ. &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ఏ. &emsp;&emsp; బ.

ప్ర. గురుః = గురవః &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; మధు = మధూని

ద్వి. గురుం = గురూన్ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; మధు = మధూని

తృ. గురుణా = గురుభిః &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; మధునా = మధుభిః

చ. గురవే = గురుభ్యః &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; మధునే = మధుభ్యః

పం. గురోః = గురుభ్యః &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; మధునః = మధుభ్యః

ష. గురోః = గురూణాం &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; మధునః = మధూనాం

స. గురౌ = గురుషు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; మధుని = మధుషు

సం. హేగురో! = హేగురవః! &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; హేమధు! = హేమధూని!

దర్శనీయః, దృష్టిః = చూడఁ &emsp;&emsp;&emsp;&emsp;&emsp; శ్రవణం = వినుట

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [దగినవాడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; శ్రోతుం = వినన్, వినుటకు

విజ్ఞాప్తిః, విజ్ఞాపనీయః = మనవి &emsp;&emsp; చేతుం = ప్రోగుచేయన్,

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చేసికొనఁదగినవాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ప్రోగుచేయుటకు

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; శమయతి = ఆర్పుచున్నాఁడు

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; ఝ్లేలతి = ఆడుచున్నాఁడు

లవ్యః, లవనీయః = కోయఁదగిన &emsp;&emsp; మార్గయతి = వెదకుచున్నాఁడు

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [వాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; గళతి = జాఱుచున్నాఁడు

శ్రోతవ్యః = వినఁబడవలసినవాఁడు &emsp;&emsp; మధుపటలం = తేనెపట్టు

అరే తవ గురుః గంగాంప్రతి స్నానార్థ మగచ్చత్. ఘంటాద్వయ మాసీత్. ఏతావత్పర్యంతం కిం కరోతిరే తత్ర? మాం ప్రచ్చసి కిం? కిం కరోతివా! తథా

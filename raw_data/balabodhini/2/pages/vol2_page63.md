## ద్విసప్తతితమః పాఠః = డెబ్బదిరెండవ పాఠము

పితామహః = తండ్రితండ్రి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; పరిష్కృత్యఽ= పరిష్కరించి

పితామహీ = నాయనమ్మ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; పరిష్కర్తుఽ = పరిష్కరించుటకు

మాతామహః = తల్లితండ్రి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; విశ్రామ్యతి = విశ్రమించు

మాతామహీ = అమ్మమ్మ &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

మాతులాని = మేనమామభార్య &emsp;&emsp;&emsp;&emsp; నిద్రాతి = నిద్రపోవుచున్నాఁడు

భాగినేయః = తోఁబుట్టువుకొడుకు &emsp;&emsp; విరమ్య = చాలించుటకు

కీదృశః = ఎటువంటివాఁడు? &emsp;&emsp;&emsp;&emsp;&emsp; విరంతుం = చాలించి

తాదృశః = అటువంటివాఁడు &emsp;&emsp;&emsp;&emsp;&emsp; విశ్రమ్య = విశ్రమించి

త్వాదృశః = నీవంటివాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; విభజ్య = విభజించి

యుష్మాదృశః = మీవంటివాఁడు &emsp;&emsp;&emsp;&emsp;&emsp; స్నాతి = స్నానము చేయు

మాదృశః = నావంటివాఁడు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; [చున్నాఁడు

అస్మాదృశః = మావంటివాఁడు &emsp;&emsp;&emsp;&emsp; స్నాహి = స్నానముచేయుము

&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; స్నాస్యతి = స్నానముచేయఁగలఁడు

తవ పితామహః గ్రామే అస్తివా? తాదృశః బాలకః కుత్రాపి నాస్తి; యుష్మద్భాగినేయస్య ఉపనయనం అసీదా్వ? అస్మాదృశానాం వృద్ధానాం సర్వదా యుష్మాదృశైః బాలకైః సేవా కర్తవ్యా? తేషాం వ్యవహారం ప్రచ్చ. పాకః ఆసీత్కింభో దేవతార్చనార్థం కః స్నాస్యతి. యూయం స్నాత. అరే ఇదానీమపి నిద్రాసి కిం రే. ఘంటాదశకం అసీత్; ఉత్తిష్ఠ, ఉత్తిష్ఠ. దంత ధావనం కురు. ముఖప్రక్షాళనానంతరం పుష్పాణి విభజ్య కానిచి తృష్ణేపణి రామాయ దేహి. కానిచి తృష్ణేపణి అనుజాయైపి దేహి. బాలకాః సర్వేపి కథం దోలాయంతేవా పశ్య. త్వం కదావా తథా అదోలాయథాః కిం? పతేయం కింవా ఇతి మామ అధిక భయం. అతపే ఆగచ్చ తస్మాత్ ఈషత్కాలం అస్మద్గృహే విశ్రమ్య గచ్చ. అరే దేవగృహే

వేలున్న యెడల నీవు హరికథను వినుటకు వెళ్ళుము. నా దేహమునింద గఱ్ఱి ఉన్నది. నేనును వెళ్ళను. (ఎవరును పోవద్దు = కేపి న గచ్చంతు.)

## షట్షష్ఠితమః పాఠః = అఱువదియాఱివ పాఠము

గంతవ్యః = వెళ్ళఁబడవలసినది &emsp;&emsp;&emsp;&emsp; సిధ్యతి = నెరవేరుచున్నది

పఠితవ్యః = చదువఁబడవలసినది &emsp;&emsp;&emsp; సేత్స్యతి = నెరవేరఁగలదు

పఠితః = చదువఁబడినది &emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సాధయతి = నెరవేర్చుచున్నాఁడు

పఠ్యమానః = చదువఁబడుచున్న &emsp;&emsp;&emsp; రోచతే = సయించుచున్నది

బాధ్యమానః = బాధింపఁబడుచున్న &emsp;&emsp; మర్దయతి = మర్దించుచున్నాఁడు

బాధితవ్యః = బాధింపఁబడవలసినది &emsp;&emsp; లింపతి = పూయుచున్నాఁడు

బాధితః = బాధింపఁబడినది &emsp;&emsp;&emsp;&emsp;&emsp; లేప్స్యతి = పూయఁగలఁడు

శ్వః సాయం మంగళగిరిగ్రామే రథోత్సవః భవిష్యతి. తం ద్రష్టుం వయం సర్వే గమిష్యామః; యూయమపి ఆగమిష్యథకిం? మయా పఠ్యమానం పుస్తకం అద్యసాయం సమాప్తం భవిష్యతి. ప్రథమ పుస్తకం ఇతః పూర్వమేవ పఠితం. తథాపి అస్మదుపాధ్యాయం సప్రష్ట్వా ఆగమిష్యామి. మామ హస్తే ఈషదపి ధనం నాస్తి. తతః అహాం ఘూమశకటం ఆరోఢుం న సమర్థః. అరేరే ఇతః ఇతః ఆగచ్చ. తత్ర వృశ్చిక ఇవ దృశ్యతే. దండం ఇత్థం ఆనయ; దండేన తం వృశ్చికం పీడయామి. రేపాపిష్ఠ! కిమర్థం వృథా తం బాధసే. చీదుష్ఠ! తూష్టీంభవ తూష్టీంభవ. వృశ్చికః సర్వేపి సర్వదా బాధితవ్యః ఏవ. ఏతావత్పర్యంతం బాధితః ఖలు; అలం ఇతః పరంవా [ముంచ = వదలు.] ఇదానీం త్వం వృశ్చికం అబాధథాః. సః వృశ్చికః పరలోకే త్వాం బాధిష్యతే. బాధిష్యతే చే ద్దాధతాం. ఇదానీం త్వాం అరక్షంఖలు; తత్పుణ్యం కిం భవిష్యతి? తేన పుణ్యేన మామ పరలోకే బాద్దైవ నభవిష్యతి. త్వం ఉద్యోగార్థం ప్రయత్నం

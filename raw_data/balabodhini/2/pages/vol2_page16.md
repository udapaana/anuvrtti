భార్యయొక్కఁ మేనమామలు. వారిదే యూరు?అక్కఁడే తెనాలి. తెనాలిలో పాఠశాల సాగుచున్నదా? చక్కగనే సాగుచున్నది. పాఠశాలలో నెందఱు పిల్లలున్నారు? చాలమంది పిల్లలున్నారు. అందఱును బ్రాహ్మణులేనా. ఇతరులుకూడ నున్నారా? ఇతరులు చాలమంది లేరు. అలాగా!

## అష్టచత్వారింశః పాఠః = నలువదియెనిమిదవ పాఠము

అవకాశః = వేలు &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సమావేష్టుం = చేరుటకు

హస్తః = చేయి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సమావేశయితుం = చేర్చుటకు

ఆజ్ఞాపనం = ఆజ్ఞాపించుట &emsp;&emsp;&emsp;&emsp;&emsp; సమావిశతి = చేరుచున్నాఁడు

విజ్ఞాపనం = మనవిచేయుట &emsp;&emsp;&emsp;&emsp;&emsp; సమావేక్ష్యతి = చేరఁగలఁడు

ఆజ్ఞాప్య = ఆజ్ఞాపించి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సమావేశయతి = చేర్చుచున్నాఁడు

విజ్ఞాప్య = మనవిచేసి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సమావేశయిష్యతి = చేర్చగలఁడు

సమావేశః = చేరుట &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సమావిశత్ = చేరెను

సమావేశనం = చేర్చుట &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; సమావేశయత్ = చేర్చెను

సమావిశ్య = చేరి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; రోహతి = మొలుచుచున్నది.

సమావేశ్య = చేర్చి &emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp; రూఢ్వా = మొలిచి

యుష్మద్గృహే ఉపవేష్టుం మామ ఈషదపి అవకాశః నాస్తి; కుత ఇతి చేత్. అస్మద్గృహే మమానుజస్య వివాహః భవతి; తదర్థం అహాం ప్రతిగృహం గత్వా సర్వాన్ బాంధవాన్ భోజనార్థం ఆహ్వాయేయం; యూయమ పా్యగచ్చత. శీఘ్రమేవ భవిష్యతి కిం? తద్దైవాగమిష్యామి. సర్వసమావేశనానంతరం పునర పేఁయికవారం మాం ఆహాోషిస్యసికిం? తవ హస్తే కిమస్తి దర్శయ. కిమపి నాస్తి. పాకం కర్తుం కాన్ ఆజ్ఞాపయః? బహుజనాః సంతి; గ్రామాంతరేమ స్థితాః యుష్మద్బాంధవాః సర్వే సమావిశన్ కిం? సమావిశ్య దినచతుష్టయం అసీత్. సర్వాన్ సమావేశయితుం త్వమేవ సమర్థః అస్మదావరణే తులసీవృక్షః నాస్తిరే.
